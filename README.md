# Kids Game 🎨🐾

A gentle, no-reading-required game for kids ages 3–5: an animal coloring book
(50 animals planned, including a dragon) and a shape-changing maze, picked from a
big friendly hub screen.

## Play

Open `index.html` in any browser — no install needed. Works on phones and tablets.

## How it's built

Plain HTML, CSS and JavaScript. Claude works on it in daily sessions and logs every
change in [CHANGELOG.md](CHANGELOG.md). What's coming next is in [ROADMAP.md](ROADMAP.md).
